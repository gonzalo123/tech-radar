AWS ha incorporado **GLM 5.3 de Z.ai a Amazon Bedrock**, ampliando el catálogo de modelos orientados a coding y tareas agentic de larga duración. Se trata de un Mixture-of-Experts de 753.000 millones de parámetros que puede invocarse mediante las APIs compatibles con OpenAI de Bedrock.

El modelo está diseñado para tareas que combinan generación de código, uso de herramientas y ejecución prolongada. Bedrock permite además utilizar prompt caching para reducir latencia y coste cuando las peticiones reutilizan contexto.

La incorporación es especialmente relevante para equipos que quieran evaluar GLM dentro de la misma capa de identidad, permisos y gobierno utilizada para otros modelos de Bedrock, sin desplegar infraestructura de inferencia propia.
