Microsoft ha rediseñado Copilot alrededor de tres capacidades: **Home**, que reúne Chat y Cowork; **Code**, para crear aplicaciones, dashboards, automatizaciones y workflows desde lenguaje natural; y **Autopilot**, un agente persistente capaz de continuar trabajo sin esperar un nuevo prompt.

Home incorpora además Word, Excel y PowerPoint dentro de la experiencia de Copilot. Cowork sigue orientado a tareas delegadas de principio a fin, mientras que Microsoft prepara routing automático entre Chat, Cowork y Code según el tipo de trabajo solicitado.

Code utiliza tecnología derivada de GitHub Copilot y ejecuta las soluciones en un entorno aislado que puede alojarse dentro del tenant. Microsoft también ha presentado **Copilot Managed Runtime**, actualmente en preview, para ejecutar y compartir estas aplicaciones bajo gobierno de TI.

Autopilot, anteriormente llamado Scout, mantiene identidad, memoria, ordenador y workspace propios dentro del tenant. Puede vigilar canales, retomar proyectos, ejecutar trabajo recurrente y actuar en Teams, Outlook, chats, canales y documentos bajo permisos y auditoría corporativos.

Home y Code empezarán a desplegarse mediante el programa Frontier; Autopilot ampliará su private preview a finales de septiembre. Microsoft también está introduciendo controles FinOps para gestionar créditos, familias de modelos y gasto de Cowork, Code y Copilot Managed Runtime.
