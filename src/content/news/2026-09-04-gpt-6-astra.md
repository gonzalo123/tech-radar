OpenAI ha presentado GPT-6 Astra, su nuevo modelo de frontera para computer use, desarrollo de software, investigación y trabajo profesional de varios pasos. El despliegue comenzó el 3 de septiembre para un grupo limitado de organizaciones y OpenAI prevé ampliar el acceso durante los próximos días a ChatGPT Plus, Pro, Business y Enterprise, además de la API, Microsoft Azure y AWS Bedrock.

Para desarrolladores, Astra ofrece una ventana de contexto de 1,05 millones de tokens y hasta 128.000 tokens de salida. En la API cuesta 10 dólares por millón de tokens de entrada y 50 dólares por millón de salida; las solicitudes con más de 272.000 tokens de entrada aplican tarifas superiores. El modelo admite niveles de razonamiento desde `low` hasta `max` y el uso de tools requiere Responses API.

OpenAI también ha ampliado Responses API para los flujos largos de Astra con llamadas asíncronas a tools y *mid-turn steering*, que permite enviar instrucciones adicionales mientras una respuesta continúa en ejecución. En Codex, la compañía afirma haber actualizado además el harness de computer use para aprovechar la mayor velocidad del modelo.

Astra es también el primer modelo de OpenAI clasificado en el nivel Critical de capacidad de ciberseguridad de su Preparedness Framework. La compañía ha introducido controles adicionales para este despliegue, un factor especialmente relevante para organizaciones que pretendan utilizar el modelo en agentes con acceso a herramientas, navegadores o sistemas reales.
