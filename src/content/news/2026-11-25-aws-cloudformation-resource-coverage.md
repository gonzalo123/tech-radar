AWS anunció el 24 de noviembre la incorporación de 206 tipos de recursos de 88 servicios a CloudFormation. Entre ellos figuran AgentCore PolicyEngine, SageMaker Hub y las instantáneas de EC2.

Cloud Control API incorpora los mismos tipos y añade otros 224 de solo lectura, repartidos entre 99 servicios. Estos últimos permiten consultar recursos existentes, no modificarlos.

La ampliación está disponible en las regiones donde opera cada servicio subyacente. Para equipos que gestionan infraestructura como código, reduce la necesidad de recurrir a recursos personalizados o llamadas externas para cubrir componentes que antes no estaban soportados.
