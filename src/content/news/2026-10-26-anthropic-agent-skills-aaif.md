Anthropic anunció el 22 de octubre que dona Agent Skills, el estándar abierto para proporcionar instrucciones, scripts y recursos reutilizables a los agentes de IA, a la Agentic AI Foundation (AAIF), bajo la Linux Foundation. La transferencia incluye el nombre, la marca, la organización de GitHub y el dominio del proyecto.

Agent Skills utiliza carpetas con un archivo SKILL.md y, cuando es necesario, scripts y referencias. Anthropic afirma que el formato se ha integrado en más de 70 plataformas, entre ellas ChatGPT, Cursor, GitHub Copilot y VS Code, y que la comunidad ha publicado un millón de skills.

La fundación mantendrá el estándar bajo gobernanza abierta. Entre las propuestas iniciales figuran versiones formales, un proceso de cambios y orientaciones de seguridad para autores y usuarios. No será necesario pertenecer a la fundación para utilizar o contribuir al estándar.

El cambio es relevante para equipos que comparten capacidades entre distintos agentes: refuerza la posibilidad de mantener habilidades portables sin depender de la hoja de ruta de un único proveedor. La gobernanza común no elimina, sin embargo, la necesidad de revisar los permisos y el código que ejecuta cada skill.
