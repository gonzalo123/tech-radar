GitHub anunció el 28 de octubre la disponibilidad general de Copilot Fusion, un sistema que selecciona y coordina modelos para tareas de programación sin exigir que el desarrollador elija manualmente uno en cada paso. Integra la selección automática de Copilot y la orquestación multimodelo del proyecto HydraFusion.

El usuario escoge entre tres niveles de esfuerzo: Standard, High y Max. Según la tarea, Fusion puede ejecutar un solo modelo, comenzar con uno económico y escalar si una comprobación de calidad lo exige, o pedir a otro modelo que revise la solución inicial. Los administradores pueden limitar qué modelos son elegibles y establecer Fusion como opción predeterminada.

GitHub afirma que Fusion Max obtuvo 60 puntos en Artificial Analysis Coding Agent Index, a dos puntos de Claude Code con Opus 5.5 Max, con aproximadamente la mitad del coste medio por tarea y menos tiempo de ejecución. Son resultados comunicados por GitHub y pueden variar según la carga de trabajo.

La facturación suma el uso de cada modelo a su tarifa habitual, con un descuento temporal del 30 % para determinados planes de pago. Copilot Fusion está disponible en VS Code, la aplicación de Copilot, Copilot CLI y los IDE de JetBrains.

La novedad puede reducir el trabajo de elegir modelos para cada tarea, aunque los equipos deberían medir calidad, latencia y consumo real antes de delegar completamente esa decisión.
