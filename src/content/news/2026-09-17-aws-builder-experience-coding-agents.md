AWS lanzó el 16 de septiembre una experiencia simplificada para iniciar proyectos que reduce la configuración inicial y permite conectar un coding agent con un solo prompt. El proceso instala automáticamente AWS CLI y Agent Toolkit for AWS, y conecta el agente al proyecto con orientación integrada para desplegar recursos siguiendo las prácticas recomendadas de AWS.

La nueva experiencia crea el proyecto con valores predeterminados y simplifica también la gestión de acceso. Los miembros del equipo pueden incorporarse mediante invitación por correo y un nuevo IAM role manager configura automáticamente el acceso entre muchos de los recursos creados por el proyecto.

AWS incorpora además controles de coste a nivel de proyecto. Al pasar a un plan de pago se puede establecer un límite mensual de gasto; si el proyecto alcanza ese límite, queda pausado durante el resto del mes. Cada proyecto puede mantener sus propios miembros y presupuesto.

Para la mayoría de nuevos clientes, el alta no requiere tarjeta de crédito y AWS ofrece hasta 200 dólares en créditos del Free Tier. Si el proyecto necesita más control, puede activar posteriormente capacidades avanzadas como múltiples regiones y gobernanza personalizada sin migración ni interrupción.

En la práctica, AWS está acercando el flujo de creación de infraestructura al trabajo con agentes de programación: un agente puede pasar de una cuenta recién creada a desplegar recursos sin que el desarrollador tenga que preparar manualmente CLI, credenciales y configuración básica del proyecto.
