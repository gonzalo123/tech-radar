React 19.3 ya está disponible en npm y convierte en estables dos APIs que hasta ahora eran experimentales: View Transitions y Fragment Refs. La versión también incorpora nuevas capacidades en React DOM, soporte para Trusted Types y cambios en React Server Components.

`<ViewTransition>` permite animar entradas, salidas, movimientos y cambios de tamaño aprovechando la View Transition API del navegador. React puede elegir la animación según cómo cambia el árbol y permite personalizar comportamientos para transiciones de entrada, salida, actualización o elementos compartidos. Por ahora esta API solo funciona en el DOM.

Fragment Refs permiten referenciar grupos de elementos sin añadir un nodo contenedor adicional al DOM. React 19.3 añade además soporte de Trusted Types en React DOM y permite renderizar `<Context>` directamente en Server Components.

Para aplicaciones React que evitaban las APIs experimentales, esta versión convierte varias capacidades de interfaz y seguridad en opciones soportadas para producción sin necesidad de adoptar una nueva versión mayor del framework.
