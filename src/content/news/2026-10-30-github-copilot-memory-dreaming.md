GitHub anunció el 28 de octubre una ampliación del contexto disponible para sus agentes de programación. Copilot Memory está disponible de forma general en planes de pago y permite conservar preferencias personales, convenciones del repositorio e instrucciones útiles entre sesiones y clientes.

Las memorias pueden utilizarse desde la aplicación Copilot, CLI, VS Code, el agente en la nube, las revisiones de código y otras superficies compatibles. Según datos comunicados por GitHub durante la vista previa, el uso de memoria mejoró la adhesión a las preferencias del desarrollador en el 93 % de las sesiones analizadas que la utilizaron; esa cifra no equivale a una mejora universal.

La función Copilot dreaming, todavía en vista previa pública, revisa el trabajo anterior para actualizar memorias y proponer mejoras en instrucciones y skills del repositorio. GitHub también amplía la búsqueda de código más allá del checkout local, con controles de acceso y disponibilidad dependientes de la función.

El cambio reduce la necesidad de repetir convenciones en cada sesión, pero obliga a gobernar qué información conserva el agente y cómo se revisan las instrucciones que genera o modifica.
