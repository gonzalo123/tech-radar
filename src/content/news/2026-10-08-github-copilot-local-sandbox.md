GitHub anunció el 7 de octubre la disponibilidad general del aislamiento local para GitHub Copilot CLI, la aplicación Copilot y las sesiones de VS Code que utilizan Agent Host. Esta capacidad permite ejecutar tareas de agentes dentro de un entorno local con restricciones, en lugar de concederles acceso sin límites al equipo.

Para equipos que utilizan agentes de programación, el aislamiento ofrece una capa adicional de control sobre las operaciones realizadas por herramientas y comandos. Su adopción no sustituye la revisión de permisos ni las políticas de seguridad de los repositorios.
