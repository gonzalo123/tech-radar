AWS anunció el 22 de octubre que Open Responses se incorpora a la Agentic AI Foundation (AAIF) como proyecto de especificación abierta para llamadas a modelos de lenguaje, respuestas en streaming y uso de herramientas. La iniciativa busca que las aplicaciones puedan utilizar distintos proveedores sin reescribir su lógica de integración.

La especificación define estructuras comunes de petición y respuesta, eventos de streaming, estados de ejecución y llamadas a herramientas. También permite extensiones específicas de cada proveedor mediante espacios de nombres. El proyecto incorpora pruebas de conformidad y evoluciona bajo gobernanza abierta junto a otros estándares del ecosistema de agentes.

AWS participa en el desarrollo y señala que Amazon Bedrock admite la API Responses desde diciembre de 2025. Su implementación permite utilizar clientes compatibles con la API de OpenAI para acceder a distintos modelos en Bedrock, con opciones de conversación con estado, herramientas y streaming.

La adopción de una interfaz común puede reducir el coste de cambiar de modelo o proveedor, aunque las capacidades particulares y la compatibilidad real siguen dependiendo de cada implementación. La especificación continúa evolucionando.
