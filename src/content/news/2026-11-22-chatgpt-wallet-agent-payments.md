OpenAI presentó el 13 de noviembre ChatGPT Wallet, un sistema de pago para agentes que permite completar compras en nombre de una persona sin exponerle el número real de su tarjeta. El lanzamiento inicial está limitado a usuarios Pro mayores de 18 años en Estados Unidos, con tarjetas elegibles emitidas en ese país, a través de dots.

Antes de cada compra, el usuario revisa los productos, el importe y la tarjeta seleccionada y autoriza la operación mediante una comprobación de seguridad, como reconocimiento facial o huella. La red de pagos emite entonces un token que sustituye los datos reales de la tarjeta durante el proceso de compra. El comerciante conserva la relación comercial y las responsabilidades de entrega y devoluciones.

OpenAI ha trabajado con American Express, Chase, Mastercard y Visa. También ha publicado una guía para comercios que aborda información de productos, acceso de agentes a las webs, solicitudes firmadas mediante Web Bot Auth y compatibilidad con los sistemas antifraude. Los comercios pueden exponer herramientas WebMCP o plugins para facilitar operaciones.

La autorización autónoma de compras dentro de límites predefinidos es una posibilidad futura, no una función anunciada como disponible. El lanzamiento actual requiere aprobación humana para cada pago. La noticia se recupera en la revisión retrospectiva semanal.
