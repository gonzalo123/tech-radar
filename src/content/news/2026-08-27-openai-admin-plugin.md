OpenAI presentó el 25 de agosto un plugin de administración para ChatGPT Work y Codex. Los administradores pueden consultar actividad y consumo de créditos, gestionar miembros y grupos, revisar permisos efectivos y controlar el acceso a funciones o modelos desde una conversación.

El plugin admite también cambios en límites de uso y solicitudes de gasto. Cada petición se traduce en una acción de lectura o escritura compatible, limitada por el rol y los permisos que ya tiene el administrador; el plugin no amplía ese acceso. El resultado indica si la operación terminó y qué cambió, y las acciones de mayor alcance pueden revisarse antes de aplicarse.

OpenAI incluye automatizaciones para comprobaciones recurrentes y solicitudes numerosas. Entre los ejemplos documentados están enviar peticiones de gasto pendientes a Slack o Microsoft Teams para su aprobación y conceder acceso automáticamente cuando una solicitud cumple criterios predefinidos, dejando las excepciones para revisión humana.

El plugin se habilita en la configuración del espacio de trabajo y se instala desde el directorio de plugins de ChatGPT Work en la web o la aplicación de escritorio. Para organizaciones que administran ChatGPT Work y Codex, concentra análisis de adopción, control de costes y operaciones rutinarias sin sustituir las políticas ni los mecanismos de aprobación existentes.
