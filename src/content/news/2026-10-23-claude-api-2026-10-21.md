Anthropic publicó el 21 de octubre la versión 2026-10-21 de Claude API y nuevas versiones principales de sus SDK, entre ellos Python 2.0.0 y TypeScript 1.0.0. Las nuevas bibliotecas utilizan esa versión de API por defecto y requieren revisar incompatibilidades antes de actualizar.

La API deja de aceptar los parámetros de muestreo temperature, top_p y top_k; enviarlos provoca un error 400. También rechaza determinados bloques document y citas en posiciones antes permitidas, y renombra campos de administración y analítica. Los SDK cambian el envío de claves de X-Api-Key a Authorization: Bearer, una diferencia importante para proxies que inspeccionan o modifican cabeceras.

En Amazon Bedrock, la versión 2026-10-21 solo está disponible para Claude 4.7 y posteriores. Las integraciones con modelos anteriores deben mantener la versión previa del SDK o migrar primero de modelo. Anthropic publica una guía de migración con las modificaciones de código necesarias.

Los equipos que utilicen Claude en servicios Python, pasarelas de API o agentes sobre Bedrock deberían comprobar versiones fijadas, parámetros de generación, autenticación y pruebas de regresión antes de desplegar las nuevas bibliotecas.
