GitHub anunció el 2 de octubre la disponibilidad general de las solicitudes de revisión de código de **Copilot mediante las APIs REST y GraphQL**. Cada petición puede especificar el nivel de esfuerzo de revisión, lo que permite incorporar el análisis a scripts, workflows y herramientas internas.

La capacidad está disponible en los planes Pro, Pro+, Max, Business y Enterprise. Es una nueva vía para iniciar revisiones, no un anuncio de un motor de análisis diferente.

GitHub también confirma que **Balanced** sustituyó a Default como esfuerzo predeterminado el 28 de septiembre, tanto para repositorios nuevos como existentes. Las configuraciones que habían elegido Lite explícitamente se respetan. El ajuste puede gestionarse a nivel de empresa, organización, repositorio o cuenta personal.
