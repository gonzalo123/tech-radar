GitHub anunció el 10 de octubre cambios en Copilot para los IDE de JetBrains. Los administradores empresariales pueden establecer mediante políticas el modelo predeterminado de nuevas conversaciones, aunque los usuarios conservan la posibilidad de elegir otro modelo.

Una nueva opción permite desactivar el arranque automático de servidores MCP configurados para Copilot y Claude. También se incorpora una acción para solicitar a Copilot la corrección de problemas desde el menú de diagnósticos.

La actualización mejora además la navegación por conversaciones y el manejo de cuentas. GitHub ha dejado de admitir JetBrains IDE 2025.1: el complemento requiere la versión 2025.2 o posterior.
