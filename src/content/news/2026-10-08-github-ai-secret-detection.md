GitHub anunció el 7 de octubre un modelo especializado para detectar credenciales filtradas mediante el análisis del código que las rodea, incluso cuando las contraseñas no siguen un patrón reconocible. Los clientes que ya reciben alertas de contraseñas detectadas por IA han pasado automáticamente al nuevo modelo.

La detección contextual durante el push está en vista previa privada, mientras que su integración con las revisiones de seguridad de Copilot está prevista para una próxima vista previa. Por tanto, estas dos funciones todavía no están disponibles de forma general.

Las alertas existentes siguen incluidas sin coste adicional en GitHub Secret Protection y GitHub Advanced Security. Las nuevas comprobaciones opcionales consumirán AI Credits cuando se habiliten, por lo que los administradores deberán revisar políticas y presupuestos antes de activarlas.
