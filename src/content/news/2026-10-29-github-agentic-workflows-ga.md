GitHub anunció el 28 de octubre la disponibilidad general de Agentic Workflows. Permite describir tareas con agentes mediante archivos Markdown y compilarlas a workflows estándar de GitHub Actions.

Entre sus usos están clasificar incidencias, analizar fallos de integración continua, actualizar documentación y escribir pruebas. Admite Copilot y agentes de programación de otros proveedores.

La ejecución reutiliza runners y políticas de Actions. Incorpora permisos de lectura por defecto, contenedores aislados, controles de red y validación de resultados antes de aplicar cambios. La versión general añade soporte para Actions Runner Controller, Docker-in-Docker, previsiones de consumo y aislamiento mediante micro-VM.

Está disponible en GitHub Free, Team y Enterprise. El uso del motor predeterminado Copilot CLI requiere una licencia de Copilot.

Para equipos con procesos de desarrollo repetitivos, ofrece una forma de incorporar agentes a la automatización existente sin desplegar un orquestador independiente.
