OpenAI anunció el 4 de noviembre un acuerdo para adquirir Pierre Computer, la empresa creadora de Code Storage y varias bibliotecas abiertas para herramientas de desarrollo. La adquisición está sujeta a condiciones habituales y aprobaciones regulatorias: no se ha cerrado todavía.

Pierre ya suministra a Codex dos componentes, Trees y Diffs, para explorar archivos y revisar cambios. También desarrolla Highlights, un resaltador de sintaxis diseñado para actualizarse mientras se escribe o un agente transmite código, y Code Storage, una API que almacena código y su historial mediante Git.

OpenAI quiere integrar estas capacidades en una plataforma donde los agentes no solo escriban código, sino que también gestionen ramas, revisiones y entregas. La compañía relaciona la operación con Pando, su backend interno de control de versiones diseñado para escalar el trabajo simultáneo de desarrolladores y agentes.

Según OpenAI, los proyectos de código abierto de Pierre seguirán siendo abiertos y los clientes de Code Storage podrán continuar usando el servicio después del cierre mientras se planifica su integración en Codex.

La operación no supone que Codex sustituya hoy a GitHub ni que Code Storage ya forme parte de la oferta general de OpenAI. Sí indica una apuesta por controlar más piezas del ciclo de desarrollo con agentes.
