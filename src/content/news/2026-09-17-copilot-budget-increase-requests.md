GitHub hizo generalmente disponible el 16 de septiembre un flujo para solicitar más presupuesto de Copilot cuando un usuario agota los AI credits asignados. En lugar de quedar bloqueado hasta una intervención administrativa externa, el usuario puede iniciar la petición en el momento en que alcanza el límite.

La solicitud se dirige automáticamente a la cuenta que financia el presupuesto. Los propietarios de organizaciones, propietarios de enterprise y billing managers pueden revisar las peticiones pendientes, ajustar la cantidad solicitada y aprobarlas o rechazarlas desde la configuración correspondiente.

Cuando un administrador aprueba el incremento, GitHub actualiza el presupuesto del usuario y restaura inmediatamente el acceso a las funciones de Copilot que consumen AI credits.

La función está disponible para GitHub Copilot Business y GitHub Copilot Enterprise con facturación basada en uso. El cambio no reduce el consumo, pero convierte el límite de presupuesto en un control operativo menos disruptivo para equipos que utilizan intensivamente agentes y modelos facturados por créditos.
